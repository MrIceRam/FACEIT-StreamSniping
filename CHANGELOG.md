# Changelog

## [1.3] — 2026-10-22

### Исправлено
- Twitch: стрим никогда не определялся как LIVE — decapi.me для идущего эфира возвращает аптайм (`2 hours, 5 minutes`), а не `is live`.
- YouTube: ссылки вида `youtube.com/channel/UC…`, `/c/…`, `/user/…` превращались в несуществующий `@UC…`; теперь проверяется правильный путь канала.
- YouTube: записи прошедших эфиров и анонсы (`isLiveContent`, `isUpcoming`) больше не считаются LIVE.
- Twitch: из Steam-ссылки вида `twitch.tv/name/videos` бралось `videos` вместо имени канала.
- Повторный скан (кнопка обновления) во время текущего скана запускал два параллельных скана, которые перетирали прогресс друг друга.
- Faceit — SPA: при переходе в комнату без перезагрузки страницы скан не запускался.
- Несколько найденных стримов подряд затирали уведомления друг друга (один ID уведомления).
- Невалидные для Twitch ники (с `.`/`-`) больше не отправляются в decapi.
- Версия в `manifest.json` (была 1.0) синхронизирована с README.

### Изменено
- Структура проекта: код в `src/` (background / content / popup), иконки в `icons/`, стили popup вынесены в `popup.css`.
- `host_permissions` сужены с `<all_urls>` до Faceit, Steam и YouTube; background загружает только разрешённые хосты.
- Сообщение `fetchSteam` переименовано в `FETCH_HTML` (используется и для YouTube).
- Добавлены `.gitignore`, `.editorconfig`, `CHANGELOG.md`.

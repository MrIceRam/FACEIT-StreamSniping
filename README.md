# FACEIT-StreamSniping

Расширение для браузера, которое смотрит, кто из игроков в матче Faceit стримит прямо сейчас на Twitch или YouTube.

![license](https://img.shields.io/badge/license-MIT-green)

## Зачем это

## Что умеет

- Достаёт состав обеих команд через Faceit API.
- Ищет каналы каждого игрока в нескольких местах: в профиле Faceit, в Steam, и просто по нику.
- Если по точному нику ничего не нашлось — генерирует кучу похожих вариантов (`nick_name` → `nickname`, `nick-name`, `nickname123` и т.д.) и проверяет их тоже.
- Проверяет, идёт ли стрим прямо сейчас, а не просто существует ли канал.
- Показывает всё в popup с иконками Twitch/YouTube.
- Сначала проверяет врагов, потом своих. Логично — про соперника знать важнее.

Если коротко — открываешь матч, кликаешь на иконку в браузере, видишь готовую картину: у кого стрим, у кого просто канал есть, у кого ничего.

## Установка

Расширение не в сторе, ставится вручную. Это несложно.

1. Скачай папку с проектом (через `git clone` или кнопкой Code → Download ZIP на GitHub).
2. Открой в браузере `chrome://extensions/` (в Opera — `opera://extensions/`, в Edge — `edge://extensions/`).
3. Включи переключатель «Режим разработчика» в правом верхнем углу.
4. Нажми «Загрузить распакованное расширение» и выбери папку проекта.
5. Готово. Расширение появилось в списке, можно пользоваться.

## Как пользоваться

Открываешь страницу матча на Faceit (адрес вида `faceit.com/room/...`), ждёшь пару секунд, тыкаешь на иконку расширения — там всё будет.

Справа от ника две кнопки: фиолетовая — Twitch, красная — YouTube. Они кликабельны, если канал найден. Если кнопка серая — значит ничего не нашлось.

Кнопка с круговой стрелкой в шапке popup — перезапустить проверку. Полезно, если матч только что начался и кто-то включил стрим уже после первого скана.

Что означают подписи под ником:

- **LIVE — Twitch** или **LIVE — YouTube** — стримит прямо сейчас, мигающая красная точка.
- **LIVE — ... (похож.)** — нашли по похожему нику. Может быть, тот человек, а может просто совпадение. Пунктирная рамка вокруг карточки — чтобы не путать.
- **Канал оффлайн** — канал есть, но эфира нет. Ссылка всё равно работает, можно посмотреть записи.
- Прочерк — вообще ничего не нашли.

## Как оно устроено внутри

Manifest V3, обычное расширение на чистом JS без библиотек.

| Файл | Что делает |
|------|-----------|
| `manifest.json` | Конфиг |
| `background.js` | Service worker. Уведомления и fetch в обход CORS |
| `showPlayer.js` | Основная логика — работает на странице Faceit |
| `nickVariations.js` | Генератор похожих ников |
| `popup.js` и `main.html` | Само окошко расширения |

Общий ход работы:

1. Ловишь URL комнаты, вытаскиваешь из него ID матча.
2. Стучишься в Faceit API, получаешь состав обеих команд.
3. По своему Faceit ID определяешь, в какой ты команде — чтобы врагов проверять первыми.
4. Идёт первая фаза: проверка Faceit-профиля, Steam-профиля, прямого ника.
5. Потом вторая фаза: перебор похожих ников. Она долгая, поэтому запускается отдельно — тебе уже показали результат первой, а вторая догоняет в фоне.

Промежуточные результаты складываются в `chrome.storage.local`, popup их читает и перерисовывает на лету.

## Про баны

Такое расширение — серая зона. По-человечески: **если тебя забанят на Faceit или на стриминге — я за это не отвечаю.** Ты сам решаешь, использовать это или нет. Основной сценарий бана — если ты палишь инфу со стрима в игре или в войсе и стример это заметит.

Не используй расширение, чтобы кого-то слить. Это просто инструмент, чтобы знать, у кого из соперников есть открытый стрим.
